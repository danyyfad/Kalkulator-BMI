cara menjalankan kalkulator bmi
1. Buka project Kalkulator BMI di Apache NetBeans IDE 25.
2. Pastikan seluruh dependensi JavaFX berhasil dimuat oleh Maven.
3. Klik kanan project, lalu pilih Clean and Build.
4. Setelah proses build berhasil, jalankan aplikasi menggunakan goal Maven javafx:run.
5. Tunggu hingga jendela Kalkulator BMI terbuka.
6. Masukkan nama, berat badan (kg), dan tinggi badan (cm).
7. Klik tombol HITUNG BMI untuk menampilkan hasil perhitungan dan kategori BMI.
8. Klik tombol RESET untuk menghapus input dan menghitung kembali.
